# Changelog

Substantial learner-facing changes are recorded here. This project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses course
release tags rather than promising semantic compatibility for prose.

## Unreleased

### Added

- Runnable visits-platform reference lab spanning Docker, CI, Kubernetes,
  Helm, Terraform, Ansible, Prometheus, Grafana, Loki, and Alertmanager.
- Automated curriculum structure, link, Markdown, application, and Compose
  validation.
- Repository contribution, licensing, maintenance, and line-ending policies.
- Hands-on coverage for reusable workflows, Kubernetes production guardrails,
  Terraform-to-Ansible inventory handoff, and Prometheus recording rules.

### Changed

- Expanded all lesson abbreviation references and deepened selected production
  topics.
- Reframed the course as a practical job-ready foundation and adjusted the
  expected time commitment.

### Fixed

- Corrected the Jenkins image targets, PostgreSQL connection escaping, and
  multiprocess Prometheus metrics in the visits-platform lab.
- Made the Helm database contract runnable and explicit, expanded application
  and integration tests, and documented the standalone CI workflow layout.
